ESTHER XIN - GITHUB PAGES

No installation or build is needed for publishing. To preview, serve the repo
root with any static HTTP server (or use GitHub Pages); opening index.html from
disk does not resolve directory URLs consistently. The site uses local assets,
system fonts, lightweight JavaScript, and no analytics. Without JavaScript,
all work sections remain readable and both blog routes still work.

PUBLISH
1. Create a public repository named ethxin0011.github.io under ethxin0011.
2. Upload the CONTENTS of this folder to the repository root, preserving assets/.
   index.html must be at the root, not inside an extra folder.
3. In repository Settings > Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
4. Save and wait for deployment to succeed.
5. Verify https://ethxin0011.github.io/ in a signed-out browser.
6. Check the photo, full-size diagram, paper links, and mobile layout.
